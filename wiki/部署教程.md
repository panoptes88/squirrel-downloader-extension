# 部署教程

插件本身不下载视频，它需要一台运行 **松鼠下载器（NAS 端）** 的服务器。
本文介绍如何把服务端准备好。

## 方式一：绿联 NAS（推荐）

如果你的设备是绿联 NAS（UGOS Pro）：

1. 打开 **应用中心**，搜索「松鼠下载器」
2. 安装时会让你填两项：**下载保存目录**（选一个共享文件夹）和 **管理员密码**
3. 装完后服务端监听 **21808** 端口

> 从应用中心安装的服务端，默认只允许本机来源访问。要让浏览器插件连上来，
> 还需要放开 CORS——**见下方「CORS 配置」一节**，这是最容易卡住的一步。

## 方式二：Docker

```bash
mkdir -p /data/squirrel
cd /data/squirrel

docker run -d \
  --name squirrel-downloader \
  -p 21808:8080 \
  -e ALLOW_INSECURE=true \
  -e ALLOW_ORIGINS=* \
  -e ADMIN_PASSWORD=改成你自己的密码 \
  -v ./db:/app/db \
  -v ./downloads:/app/downloads \
  ghcr.io/panoptes88/squirrel-downloader:latest
```

> 镜像由 GitHub Actions 在每次推送 `main` 时自动构建发布，同时包含 amd64 与 arm64。
> 国内网络可将 `ghcr.io` 换成 `ghcr.1ms.run` 加速。

### Docker Compose

```yaml
services:
  squirrel-downloader:
    image: ghcr.io/panoptes88/squirrel-downloader:latest
    container_name: squirrel-downloader
    restart: unless-stopped
    ports:
      - "21808:8080"          # 容器内固定 8080，宿主机暴露 21808
    volumes:
      - ./downloads:/app/downloads   # 成品视频
      - ./db:/app/db                 # 任务与账号数据库
    environment:
      - ALLOW_INSECURE=true
      - ALLOW_ORIGINS=*               # 插件必需，见下节
      - ADMIN_PASSWORD=改成你自己的密码
      - TZ=Asia/Shanghai
      - LANG=C.UTF-8                  # 中文文件名
```

```bash
docker compose up -d
```

## 验证服务

浏览器打开 `http://你的服务器IP:21808`，应该看到登录页。

- **用户名**：`admin`
- **密码**：你上面设置的 `ADMIN_PASSWORD`

## CORS 配置（插件必需，最容易漏）

浏览器插件的请求来源是 `chrome-extension://<扩展ID>`，服务端默认只放行
`http://localhost:8080` 一类的来源，**不允许插件访问**。

**必须把 `ALLOW_ORIGINS` 设置为 `*`**，插件才能正常发送下载任务。

```bash
# 已经在跑的容器，最省事的做法是重建
docker rm -f squirrel-downloader
# ……再按上面的 docker run 重新起一次，注意带上 -e ALLOW_ORIGINS=*
```

如果不想用 `*`，也可以只放行自己的插件：

```
ALLOW_ORIGINS=chrome-extension://abcdefghijklmnopabcdefghijklmnop
```

扩展 ID 可以在 `chrome://extensions/` 的插件卡片上看到。

> ⚠️ **绿联应用中心安装的用户注意**：应用中心版的编排文件没有暴露 `ALLOW_ORIGINS`，
> 插件可能连不上。解决办法有两个：
> 1. 改用上面的 Docker 方式部署（可以自由设置环境变量）；
> 2. 在应用中心的应用配置里找找是否有相关设置项——如果没有，请向开发者反馈。

## 环境变量说明

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | 8080 | 容器内服务端口（建议不要改） |
| `DOWNLOAD_DIR` | /app/downloads | 下载目录 |
| `BIN_DIR` | /app/bin | 外部工具目录 |
| `DB_PATH` | /app/db/data.db | 数据库路径 |
| `LANG` | C.UTF-8 | 字符编码（中文文件名需要） |
| `ADMIN_PASSWORD` | admin123 | 管理员密码（**请务必修改**） |
| `TZ` | Asia/Shanghai | 时区 |
| `ALLOW_INSECURE` | false | 允许 HTTP 访问（局域网部署需设为 `true`） |
| `ALLOW_ORIGINS` | localhost | CORS 来源（**插件需设为 `*`**） |
| `DOWNLOAD_TIMEOUT` | 0 | 下载超时（秒），0 = 不限制 |

## 更新服务

```bash
cd /data/squirrel
docker compose pull
docker compose up -d
```

## 下载的文件在哪里？

Docker 方式保存在 `./downloads`（即 `/data/squirrel/downloads`）；
绿联应用中心方式保存在你安装时选择的那个目录。
